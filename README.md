# Talevane v0.3

Offline-first Android book reader foundation for a future AI-powered immersive reading experience.

## v0.3
- Custom Talevane launcher icon and in-app mark
- Branded launch screen
- Android TextToSpeech narration from the current reading position
- Play / pause narration
- Adjustable narration speed from 0.6× to 1.8×
- Narration follows reading progress and stores its position
- Safer bottom controls above the Android navigation bar
- Import EPUB, PDF and TXT
- Local Room library
- Resume reading from the saved position
- Live reading percentage and progress bars
- Improved library cards and metadata cleanup
- Bookmarks and adjustable font size
- Material 3 dark UI
- No account, no subscription, no AI dependency

## Current narration scope
v0.3 uses the text-to-speech engine installed on the Android device. Background playback, voice packs, sentence highlighting and AI-directed narration are later milestones.

## Canonical rule
Future AI may analyze context for narration, mood and soundtrack systems, but must never rewrite the source book text.
